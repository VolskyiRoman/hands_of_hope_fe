# AidBridge

A platform that helps people affected by the war find verified support services and get first-line medical guidance from an AI assistant.

## Features

- **AI medical assistant.** Answers first-aid and health questions, detects emergencies, and points users to nearby care.
- **Services directory.** Verified hospitals, pharmacies, shelters, and psychological and legal aid.
- **Help requests.** People ask for help, and volunteers respond.
- **Ukrainian and English.**

## Tech stack

FastAPI · React · PostgreSQL · Docker

## Getting started

```bash
cp .env.example .env
docker compose up --build
```

- Frontend: http://localhost:5173
- API docs: http://localhost:8000/docs
